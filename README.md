<summary><strong>01. Redis Cache & Session Management System</strong> — Java · Spring Boot · Redis · MySQL</summary>

<br>

A backend engineering project demonstrating caching strategies, session lifecycle management, and integration between a relational database and an in-memory data store.

| Attribute | Details |
|---|---|
| Stack | Java, Spring Boot, Redis, MySQL, REST APIs |
| Scale | Backend application designed around cache-backed data access and user sessions |
| Performance | Reduces repeated database operations for frequently accessed data through caching |
| Security | Session expiration through TTL-based keys; additional authentication and authorization controls depend on implementation |
| Impact | Demonstrates cache-aside architecture, cache invalidation, database fallback, and session lifecycle management |

- Integrated Redis as an in-memory caching layer alongside MySQL persistence.

- Handled cache hits, cache misses, invalidation, and database fallback.
- Designed Redis-backed sessions with TTL-based expiration and cleanup.
- Tested expiration, invalidation, and concurrent-request behavior for data consistency.

**Key Engineering Concepts:** Cache-aside pattern, TTL, cache invalidation, persistence, session management, concurrency, REST API design.
